Questions, answered

      
      

        Is my pattern or test text uploaded anywhere?
        
No. Regex Tester with Explanation runs entirely in your browser. Your pattern and text stay in memory on your device, are matched by your browser's own engine, and are never sent to a server, so pasting real log lines is safe. The share link keeps the pattern after the # sign, a part of the address browsers never send to any server. You can disconnect from the internet and it keeps working.

      

      

        Which regex flavor does it test?
        
JavaScript (ECMAScript), the one used by browsers and Node.js, because matching runs on the built-in RegExp engine. PCRE-only features such as possessive quantifiers, atomic groups, recursion or \A and \Z are not supported and show an error. Lookbehind works in current browsers but not in some older Safari versions.

      

      

        What happens if my pattern is too slow?
        
Matching runs in a background worker. If a job takes longer than about one second, usually because of nested quantifiers like (a+)+ on text that almost matches, the worker is stopped and a warning appears. The page stays responsive, so you can fix the pattern straight away.

      

      

        Is it really free?
        
Yes. It is open source under the MIT license, with no account, no limits and no ads. If it saves you a paid subscription, you can say thanks on Ko-fi.

      

      

        Does it work offline?
        
Yes. After your first visit the page is cached by a service worker, so it loads without a connection. You can also install it from your browser's menu as an app.

      

      

        Was this written by AI?
        
Yes. Regex Tester with Explanation was generated by Claude Code from a written specification inside an automated pipeline, with a test suite that runs in a real browser. The full source is on GitHub, so you can read every line before you trust it with your text.
